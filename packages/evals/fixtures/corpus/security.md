# Security basics

## Passwords

Use the company password manager for every work account. Never reuse a password.

## Two-factor authentication

Two-factor authentication is mandatory on email, chat and the cloud console. Use an authenticator app or a hardware key, not SMS.

## Phishing

Forward suspicious emails to [the security team](https://wiki.northwind.example/security) at security@northwind.example and delete them. Never enter credentials from a link in an email.

## Key rotation

Encryption keys are rotated once a year. Old keys stay available for decryption until every record is re-sealed.
